WHAT TO BUILD
1. Webhook receiver module with Stripe-style signature verification in TEST MODE ONLY (no real keys, no real Stripe, no network). Parse a Stripe-Signature style header "t=<unix_ts>,v1=<hmac_hex>", compute HMAC-SHA256 over "<ts>.<raw_body>" using a webhook secret supplied via env var (tests generate a random one locally at runtime), verify with constant-time comparison, reject stale timestamps beyond a configurable tolerance (default 300s) to kill replay attacks.
2. Idempotent ledger in SQLite: record_event(event_id, idempotency_key, type, payload) returns "applied" or "duplicate". The same idempotency key arriving twice, out of order, or redelivered must produce exactly ONE ledger entry. Reconciliation logic must handle: duplicate delivery, out-of-order events for the same payment, replayed signatures (same payload re-sent with old timestamp), and distinct keys mapping to distinct entries. Every decision must be auditable: ledger rows store event_id, idempotency key, event type, payload hash, received-at, first-applied-at, and outcome (applied/duplicate/rejected with reason).
3. TDD: write the test suite FIRST (pytest), watch it fail, then implement. Cover at minimum: valid signature accepted; invalid signature rejected; tampered payload rejected; stale timestamp rejected (replay); missing header rejected; malformed header rejected; duplicate delivery collapses to one ledger entry; out-of-order events reconcile to one entry; replay attack (old ts, valid sig) rejected; missing idempotency key handled safely; distinct keys give distinct entries. Every test must be a real test — no placeholders.
4. scripts/redelivery_storm.py: a redelivery-storm script that fires N webhook deliveries (mix of duplicates, replay attempts, and out-of-order events) at the ledger and prints measured results: total deliveries sent, unique idempotency keys, ledger entries created, duplicates collapsed, rejections. The invariant: ledger entries == unique idempotency keys, every time.
5. requirements: pytest only. Keep the package stdlib-only otherwise (hmac, hashlib, sqlite3). Fast, no network.
